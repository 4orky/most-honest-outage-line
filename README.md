One honest status page line for a total server outage — plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know. The program drafts ten candidate lines, scores them deterministically on honesty, status page voice, admitted uncertainty, tight wording and specificity, and writes the best one to `/output/entry.txt`:

> Every service I run is down — API, dashboard, login — and my own monitoring is unreachable too, so I can't yet tell you what broke or when it will be back.

## Run it

```sh
python3 main.py
```
